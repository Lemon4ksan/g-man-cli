# Plan: Run tf2autobot unchanged via g-mand

## Goal

Run tf2autobot as-is, replacing only Steam connection layer with g-mand. Zero changes to tf2autobot code.

## Approach: npm package aliasing

Replace Steam-specific npm packages with g-mand adapters that have the same API.

### Packages to replace

| Original package | g-mand adapter | Why |
|---|---|---|
| `steam-user` | `@node-gman/steam-user` | Steam login, persona, friends |
| `@tf2autobot/tradeoffer-manager` | `@node-gman/tradeoffer-manager` | Trade offers |
| `@tf2autobot/tf2` | `@node-gman/tf2` | TF2 Game Coordinator |
| `@tf2autobot/steamcommunity` | `@node-gman/steamcommunity` | Steam Community |

### How it works

In tf2autobot's package.json, use npm aliases:

```json
{
  "dependencies": {
    "steam-user": "npm:@node-gman/steam-user@^1.0.0",
    "@tf2autobot/tradeoffer-manager": "npm:@node-gman/tradeoffer-manager@^1.0.0",
    "@tf2autobot/tf2": "npm:@node-gman/tf2@^1.0.0",
    "@tf2autobot/steamcommunity": "npm:@node-gman/steamcommunity@^1.0.0"
  }
}
```

tf2autobot code imports `steam-user` → npm resolves to `@node-gman/steam-user` → talks to g-mand.

### Implementation order

1. **@node-gman/steam-user** — most critical, handles login/connection
2. **@node-gman/tradeoffer-manager** — trade operations
3. **@node-gman/tf2** — GC operations
4. **@node-gman/steamcommunity** — community operations

### What stays native (no replacement)

| Package | Why |
|---|---|
| `@tf2autobot/tf2-schema` | Schema loading from pricedb.io |
| `@tf2autobot/tf2-sku` | SKU parsing (pure JS) |
| `@tf2autobot/tf2-currencies` | Currency math (pure JS) |
| `@tf2autobot/bptf-listings` | BPTF API (HTTP) |
| `@tf2autobot/bptf-login` | BPTF login (HTTP) |
| `steam-totp` | TOTP generation (pure JS) |
| `steamid` | SteamID parsing (pure JS) |

### Test plan

1. `npm install` in tf2autobot (with aliases)
2. `npm run build` (tf2autobot compiles unchanged)
3. Start g-mand daemon
4. Start tf2autobot with `npm start`
5. Bot connects via g-mand
6. Receive trade offer → MyHandler processes → action via g-mand
7. Verify: login, GC, trade offers, chat messages all work
